# 提示词评测调优平台（Prompt Evaluation & Optimization Platform）

纯前端单文件应用：用真实大模型评测 "提示词生成效果"，并根据评分证据自动调优提示词，形成「生成 → 评分 → 归因 → 优化 → 对比」的闭环。

让 "提示词写得好不好" 从主观感觉，变成可评分、可归因、可对比、可自动迭代验证。



***

## 功能特性



* **评测集管理**：自定义字段与样本、提示词模板（`{变量}` 占位符自动替换）、AI 辅助优化提示词。

* **批量推理**：选择评测集 + 生成模型，逐条真实生成内容。

* **多维度自动评分**：按自定义维度（相关性、忠实度、字数、格式等）加权打分，输出分维度评分依据、成功率与耗时。

* **提示词优化**：基于评分证据自动归因问题、给出优化建议、生成新版提示词（保留变量占位符，不覆盖原版）。

* **新旧对比**：新版与原版同参数跑全流程，平均分 / 成功率 / 各维度分对比 + diff 高亮，支持与原版 / 上一版切换对比。

* **自动调优**：多轮迭代，可设轮数上限或达标阈值（平均分 / 各维度最低分）自动停止，并推荐最佳版本；可中途手动停止。

* **模型无关**：内置多种模型接入与统一适配器，支持自定义接口。



***

## 运行方式

纯静态、零依赖、无需安装与构建。

**方式一：直接打开**

双击 `index.html`，用浏览器打开即可。

**方式二：本地静态服务器（推荐，避免&#x20;**`file://`**&#x20;下部分浏览器的接口限制）**



```
python -m http.server 8901
# 浏览器访问 http://127.0.0.1:8901/index.html
```

**方式三：部署到静态托管**

上传到 GitHub Pages / Vercel / Netlify / 对象存储等任意静态托管，即可通过公网 URL 访问运行。



***

## 模型接入说明



* 在应用内的模型下拉中选择预设模型（小米 MiMo、DeepSeek、OpenAI、Gemini、智谱、SiliconFlow、Grok、Claude、Ollama、自定义 OpenAI 兼容等）。

* 在对应模型的 API Key 输入框填写密钥即可调用；**同一模型的 Key 在应用内全局联动**，无需重复填写。

* 内置三种接口适配器：


  * **OpenAI 兼容**：`/chat/completions`（多数模型适用）

  * **Anthropic**：`messages` 接口

  * **Gemini**：`generateContent` 接口

* 自定义模型可在「自定义 OpenAI 兼容」中修改 `baseUrl` 与 `model`。

* 浏览器直连模型接口，需模型服务端支持 CORS（内置预设均已适配）。

* 评测集字段即提示词中的 `{变量}`，上传表格后按列名自动替换。



***

## 隐私说明



* API Key 仅保存在浏览器本地（`localStorage`），**不写入代码、不上传任何服务器**。

* 纯前端应用，无后端；除调用你填写的模型 API 外，无其他网络请求。

单个 HTML 文件（结构 + 样式 + 逻辑内聚），无框架、无构建依赖，可直接部署与分发。
