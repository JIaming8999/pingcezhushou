# 文案生成评测工作台

可真实调用模型的文案生成评测工具，支持批量推理、自动化评分和提示词优化。

## 功能模块

- **任务配置**：创建和管理评测集，支持 Excel/CSV 上传
- **批量推理**：调用 OpenAI 兼容 API 批量生成文案
- **评测助手**：配置评测维度（上下文相关性、忠实度/防幻觉、输出相关性）
- **自动化评分**：基于评测助手对生成结果进行自动化评分
- **提示词优化**：根据评分结果生成优化建议

## 快速开始

### 前置要求

- Node.js 18+

### 启动

```bash
# 安装依赖（无外部依赖，可跳过）

# 启动服务
node copywriting-eval-server.js
```

启动后访问 http://127.0.0.1:8787

### 自定义端口

```bash
PORT=3000 node copywriting-eval-server.js
```

## 使用说明

1. 在「任务配置」中创建评测集，添加测试样本
2. 在「批量推理」中选择评测集和模型，批量生成文案
3. 在「自动化评分」中选择评分模型和评测助手，对生成结果打分
4. 在「提示词优化」中查看评分结果，获取优化建议

## 模型配置

工作台支持 OpenAI 兼容的 API，需要配置：

- **API 地址**：支持自定义 endpoint
- **API Key**：你的模型 API 密钥
- **模型名称**：如 gpt-4、deepseek-chat 等

## 文件说明

- `copywriting-eval-workbench.html` - 主页面（包含完整前端）
- `copywriting-eval-server.js` - Node.js 服务端（提供静态文件和 API 代理）
